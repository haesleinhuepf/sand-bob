# Sand-Bob

[![Star on GitHub](https://img.shields.io/github/stars/haesleinhuepf/sand-bob?style=social)](https://github.com/haesleinhuepf/sand-bob/stargazers)

Sand-Bob is a tool for LLM-based code generation and docker-sandboxed execution with an interactive interface in Jupyter Lab. It also is a framework for studying language models and prompt-engineering performance in the context of single-script code generation for data analysis.

Note: This is research software under active development. The API may break with every new release.
